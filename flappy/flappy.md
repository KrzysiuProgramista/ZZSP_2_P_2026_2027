# Flappy (Python)

拍翅膀穿越水管，撞到就結束。單一檔案 `flappy.py`，Tkinter 深色介面，
遊戲畫面（水管、鳥、分數、所有訊息）都畫在同一個 Canvas 上，不需要任何第三方套件。

程式分三層：純物理 `FlappyGame`／`Pipe`、圖形介面 `FlappyGUI`、內建自動駕駛 `run_simulate`。

## 執行

```bash
python3 flappy.py                    # 玩（normal：缺口 130、速度 2.3）
python3 flappy.py -d easy            # 缺口 150、速度 2.0
python3 flappy.py -d hard            # 缺口 110、速度 2.5
python3 flappy.py --gap 140 --speed 2.0   # 自訂缺口與速度，會覆蓋 -d
python3 flappy.py --seed 3           # 固定水管序列
python3 flappy.py --simulate 30      # 無視窗：內建自動駕駛飛 30 秒並印出結果
python3 flappy.py --selftest         # 跑物理測試（25 項）
```

沒有 tkinter 或開不了視窗時，`--simulate` 與 `--selftest` 仍可正常使用。

## 操作

| 按鍵 | 動作 |
| --- | --- |
| Space / ↑ / W / 點擊畫面 | 拍翅膀 |
| `1` / `2` / `3` | easy / normal / hard |
| `R`、`N` 或 `F2` | 重新開始 |
| `P` | 暫停 |
| `Esc` | 離開 |

畫面文字：準備時顯示「點擊或按空白鍵」，結束時用一張卡片顯示「遊戲結束」、
「分數 X　最高 Y」與「按 R 或點擊重來」，暫停時顯示「暫停」。
目前分數以大字畫在上方中央。介面沒有選單列，難度用鍵盤切換。

## 特色

- 物理與原本的網頁版相同：重力 0.45、水管寬 60、水管間隔 150、鳥固定在 x=80；
  每次拍翅的上升高度不寫死，由 `_climb_height()` 用同一套離散迴圈算出
  `flap_rise`（預設參數下約 74.25 px）
- 水管缺口至少離天花板與地面 100 px（`EDGE_MARGIN`）
- 每穿過一根水管 +1 分，`passed` 旗標確保同一根只算一次
- 三種死因都會記錄在 `death_reason`：撞水管、撞天花板、撞地面
- 「最高」分數只保留在這次執行期間（記憶體），關掉程式就重新計算
- 深色主題：底 `#16181d`、水管 `#3f8f6b`、地面 `#2a2d35`、鳥 `#f5c542`

### 對原版做的一個公平性修正

原版每根水管的缺口都獨立隨機落在 `[100, 440]`，所以相鄰兩根可能相差 340 px ——
但它們只相隔 150 px，而一次拍翅只能上升 74 px。這種組合在物理上不可能通過，
等於開局就注定失敗。

這裡把新缺口限制在前一個缺口的 ±60% 缺口高度內（`FlappyGame.GAP_STEP_RATIO = 0.6`），
讓每根水管都在可達範圍內，`--selftest` 也會驗證連續缺口都在這個範圍。

同樣的原因，缺口小於約 96 px（74 px 上升 + 鳥身 14 px）在物理上不可能，所以 hard 用
110 px 的缺口搭配更快的捲動速度來提高難度，而不是把缺口壓到過不去。

## 結構

`flappy.py`

- `FlappyGame` / `Pipe` — 純物理、生成與碰撞，完全不碰 UI：`flap`、`step`、
  `_spawn_pipe`、`_collision`（矩形重疊）、`next_pipe`
- `FlappyGUI` — Canvas 繪製、暫停、難度切換
- `run_simulate` + `FlappyGame.autopilot_flap` — 內建自動駕駛，供 `--simulate` 與測試使用

自動駕駛的邏輯是：拍翅後會上升 `flap_rise`，所以在「升上去剛好落在缺口上緣內」的
高度才拍；另外用 6 格的預測，避免正在上升時被重力帶出缺口下緣。

`--selftest` 的 25 項檢查涵蓋：拍翅與重力（上升、減速、開始下墜）、`flap_rise` 與物理
一致、天花板／地面／水管三種死亡、死亡後不再更新、水管生成與左移、缺口維持在合法範圍、
離開畫面的水管會回收、通過計分只算一次、三種難度的預設值順序正確、連續缺口可達，
以及內建自動駕駛在三種難度各飛 60 秒（每種難度 3 個隨機種子，實測分別通過
46 / 53 / 37–57 根水管）都不會墜毀，用來證明沒有任何難度是設計上過不了的。
