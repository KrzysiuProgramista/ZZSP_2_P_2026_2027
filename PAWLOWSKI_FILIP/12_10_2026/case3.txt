EXPECTED
  Each loop iteration removes the oldest cell from the queue (FIFO), so the
  search moves outward from S and eventually dequeues C.

OBSERVED
  The program never finishes normally: after 10000 steps it prints
  "Status: STOPPED - maximum number of search steps exceeded."
  With --trace every line is identical:
    search: position=(1,1), queue_size=2, visited=2
  The position is always (1,1) = S; visited stays at 2 and the queue stays
  at size 2.

  `current = self.queue[0]`, then stepping twice. Reason: the trace shows
  the same position repeating, so I need to see what the loop does to the

  queue does not change, and so on forever. The first instruction that
  makes the state wrong is `current = self.queue[0]` (read without
  removal).

  The rule "every processed cell is removed from the queue" is violated,
  so the front of the queue never advances (infinite loop, bounded only by
  max_steps). Fix: `current = self.queue.popleft()`.
